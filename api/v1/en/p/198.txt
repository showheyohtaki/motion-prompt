Please use "Colored pencil drawing" (色鉛筆画), one of the names in "Art styles for image generation".
Motion Prompt #198

What it is: Fine pencil strokes layered over textured paper
What the sample shows: The same line drawing becomes a hand-drawn colored pencil picture, with layered fine strokes and white paper grain showing through.
Spec:
- Medium: colored pencils on paper
- Look: color built up from layered fine strokes; the paper grain shows through in white
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For friendly, hand-drawn illustrations, including ones for children.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/198.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
