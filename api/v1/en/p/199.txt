Please use "Linocut print" (リノカット), one of the names in "Art styles for image generation".
Motion Prompt #199

What it is: Bold black-and-white lines cut into a block
What the sample shows: The same line drawing becomes a black-and-white print from a carved block, made only of bold lines and shapes with no gray or blur.
Spec:
- Medium: a carved linoleum block, printed
- Look: bold lines in pure black and white, with rough marks left by the carving
- Avoid: gray, blur and gradients
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For posters, T-shirts or logos that need a strong black-and-white look.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/199.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
