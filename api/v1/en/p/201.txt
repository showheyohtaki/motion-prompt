Motion Prompt #201

What it is: Primary-color areas, bold black outlines and a few halftone dots
What the sample shows: The same line drawing becomes flat primary colors with bold black outlines, with halftone dots here and there.
Spec:
- Look: flat areas of primary color with bold black outlines; a few halftone dots here and there
- Feel: 1960s silkscreen prints
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For eye-catching ads, social images or merchandise.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/201.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
Keep the shapes, timing and easing values of the reference implementation as they are, and change only the text, colours and assets to fit what I am making.
