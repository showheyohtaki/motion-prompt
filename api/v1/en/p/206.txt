Please use "Layered paper art" (重ね切り絵), one of the names in "Art styles for image generation".
Motion Prompt #206

What it is: Cut colored paper stacked in layers, with shadows giving depth
What the sample shows: The same line drawing becomes many layers of cut colored paper; shadows fall where the layers step, giving depth.
Spec:
- Material: cut colored paper stacked in many layers
- Look: shadows fall at each step between layers, giving depth
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For warm, dimensional visuals like a picture book or a card.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/206.txt
