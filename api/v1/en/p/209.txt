Please use "Pixel art" (ドット絵（ピクセルアート）), one of the names in "Art styles for image generation".
Motion Prompt #209

What it is: Game-style pictures drawn in visible square pixels
What the sample shows: The same line drawing becomes a flat, game-style picture made of square pixels, with no depth and every pixel clearly visible.
Spec:
- Look: low resolution with every pixel (square) clearly visible
- View: a flat picture seen from the front, with no depth (for a build of cubes, see Voxel art #210)
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For game-like or retro icons and banners.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/209.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
Keep the shapes, timing and easing values of the reference implementation as they are, and change only the text, colours and assets to fit what I am making.
