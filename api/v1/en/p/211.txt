Motion Prompt #211

What it is: 3D built from flat triangular faces
What the sample shows: The same line drawing becomes 3D made only of triangular faces; each face has its own shade, so the forms look faceted.
Spec:
- Build: 3D made only of triangular faces with no gaps
- Look: each face has its own shade of color; faceted forms
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For simple, modern 3D backgrounds or icons.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/211.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
