Please use "Embroidery" (刺繍), one of the names in "Art styles for image generation".
Motion Prompt #214

What it is: A picture stitched into fabric with colored thread
What the sample shows: The same line drawing becomes embroidery in colored thread on fabric, with the stitches and the weave of the cloth visible.
Spec:
- Material: fabric and colored thread
- Look: the direction of each stitch and the weave of the cloth are visible
- Sample: the same base sketch (a line drawing of a house, a tree and the sun on a hill) was given to an image model as a reference and redrawn in this style. A diagonal wipe turns the sketch into the style from 0.5 s to 1.35 s, the picture slowly zooms to 1.045x until 4.0 s, and it fades back to the sketch from 4.0 s to 4.5 s (one pass = 4.7 s, cubic ease-in-out)
When to use it: For merchandise, packaging or seasonal greetings that should feel warm and hand-made.

Reference implementation (Canvas 2D, a function whose picture depends only on the time): https://showheyohtaki.github.io/motion-prompt/api/v1/en/e/214.txt
Shared helper code: https://showheyohtaki.github.io/motion-prompt/api/v1/kit/artstyle.js
