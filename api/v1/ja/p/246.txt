「下から現れるフッター（Reveal footer）」を使ってください。「LP・Webサイトの演出 第3弾」の名前の1つです。
Motion Prompt #246

どういうものか: 本文がめくれて固定のフッターが出る
見本で起きること: 最後までスクロールすると、白い本文が影を付けて上がっていき、その下に固定されていた青いフッターが現れる。フッターの中身は少し下から上がってくる。
仕様:
- 表示域 511×170。フッター（高さ130・青 #2F6BEB）は画面の下に固定。4.7秒でひと回り（パックの周期9.4秒で2回）
- スクロール: 0.35〜2.0秒で 0→130px、3.0〜4.35秒で 130→0（easeInOut 3乗）。本文は白でフッターの上に重なり、スクロール分だけ上がる
- 本文の下の端: 角丸 0→14（q×3 で効く）、影 ぼかし18・下へ6・不透明度 0→0.35（q×4）。q＝スクロール量 / 130
- フッターの中身は 26×(1−q) px 下から元の位置へ。見出し2行（28px、2行目は薄い青 #C9D8FB）、リンク4つ、白い丸に青い矢印のボタン
- CSS なら フッターを position: sticky; bottom: 0（または fixed）にして、本文に背景色と z-index を付けて前に出す
使いどころ: お問い合わせや採用への誘導を、ページの最後に印象よく見せたいときに。
