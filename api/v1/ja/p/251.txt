Motion Prompt #251

どういうものか: カーソルの通り道に写真が並ぶ
見本で起きること: 大きな見出しの上でカーソルを動かすと、通った所に作品の写真が次々に置かれていき、古い物から縮んで消える。
仕様:
- 表示域 511×170。見出し PORTFOLIO（54px）の上で。4.7秒でひと回り（パックの周期9.4秒で2回）
- カーソルは8の字: x = 255 + 185·sin(2πt/4.7)、y = 88 + 46·sin(4πt/4.7 + 0.6)
- 0.1175秒（4.7秒の1/40）ごとに、その時のカーソルの位置へ写真を1枚置く。写真は白い縁付き 58×72、−0.125〜0.125 rad 傾ける
- 置いた写真: 最初の12%（約0.1秒）で backOut で 0→1 に開き、55%〜100% で easeIn 3乗で縮んで消える。寿命0.85秒。新しい物ほど上
- #083 マウスストーカーは1つの丸が追いかける、#157 ホバーで画像プレビューはリストの行の写真を出す。イメージトレイルは通り道に何枚も残す
使いどころ: 写真家・デザイナー・スタジオのポートフォリオで、作品の多さを遊びながら見せたいときに。
