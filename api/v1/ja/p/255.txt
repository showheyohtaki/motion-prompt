Motion Prompt #255

どういうものか: 文字の板がめくれて替わる
見本で起きること: 黒い板に並んだ11枚の文字の板が、上下に割れてめくれ、途中の文字を何枚か経て、TOKYO 09:30 → PARIS 11:05 → SEOUL 13:40 と替わる。
仕様:
- 表示域 511×170。文字の板 34×54（角丸5）を間隔4で11枚。4.7秒でひと回り（パックの周期9.4秒で2回）
- 切り替えは 0.5・2.0・3.5秒に始まる（TOKYO 09:30 → PARIS 11:05 → SEOUL 13:40 → 最初へ）。文字 i は i×0.045秒遅れて始まる
- 1回めくるのに0.09秒。同じ文字は動かない。違う文字は途中の文字を含めて 3〜5回めくり、最後に次の文字で止まる
- 1回のめくり f（0〜1）: うしろは上半分に次の字、下半分に今の字。f < 0.5 は今の字の上半分が真ん中を軸に縦に縮んで倒れ（暗くなる）、f ≥ 0.5 は次の字の下半分が縦に伸びて下りる
- #156 テキストロールは文字が回って入れ替わる、#129 テキストスクランブルはランダムな字が入れ替わる。パタパタ表示は割れた板が倒れる形そのものを見せる
使いどころ: 旅行・イベント・カウントダウンなど、行き先や時刻・数字を、機械が切り替えるような手ざわりで見せたいときに。
