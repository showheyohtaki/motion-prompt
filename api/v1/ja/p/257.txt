Motion Prompt #257

どういうものか: 水のレンズのように背景を曲げる
見本で起きること: カラフルな見出しの上を、丸いガラスのバーが左右に動く。バーの中では下の色と文字がふくらんで見え、ふちほど強く曲がる。上のふちに白い光。
仕様:
- 表示域 511×170。背景は 青→中間の青（#2F6BEB→#9DB8F6）のグラデーションに、ぼかした丸3つ（薄い青・白・ごく薄い青、ぼかし22px）と見出し LIGHT / IN MOTION。4.7秒でひと回り（パックの周期9.4秒で2回）
- バー 176×58（角丸29）: 中心 x = 255 + 140·sin(2πt/4.7)、y = 64 + 16·sin(4πt/4.7)
- 曲げ: 背景をバーの中心を軸に拡大して重ねる。外のふち（全体）1.7倍、7px 内側から1.38倍、13px 内側から1.22倍。ふちほど強くふくらむ（屈折の代わり）
- 仕上げ: 白10% の膜、上のふちと下のふちに白い線（不透明度 0.95 と 0.6 のグラデーション）、内側に中間の青の細い線、外に影（ぼかし18・下へ6）。中にアイコン3つ
- グラスモーフィズム（すりガラスでぼかす）と違い、ぼかさずにレンズのように曲げる。Apple が2025年に発表したデザインの名前でもある
使いどころ: ナビゲーション・タブ・ボタンなど、写真や色の上に重ねる部品を、軽く新しく見せたいときに。
