「フルーテッドガラス（Fluted glass）」を使ってください。「LP・Webサイトの演出 第3弾」の名前の1つです。
Motion Prompt #258

どういうものか: 縦溝のガラス越しに色が揺れる
見本で起きること: 縦の溝が並んだガラスの板の向こうで、動く色の丸と白い輪、見出しの文字が、溝ごとに細く縮んで並んで見える。板はゆっくり左右に動く。
仕様:
- 表示域 511×170。背景は 青→中間の青 に、動く丸3つ（白・薄い青・ごく薄い青）と白い輪、見出し SOFT / FOCUS。4.7秒でひと回り（パックの周期9.4秒で2回）
- ガラスの左の端 x = 200 + 50·sin(2πt/4.7)。そこから右の端まで、溝1本 16px
- 溝1本には、うしろの 40px 分（溝の位置の 12px 左から）を、少しぼかして（2.5px）左右反転し、16px に縮めて映す
- 溝ごとに横のグラデーション: 左の端 白34% → 25% で白6% → 70% で0 → 右の端 黒18%。板全体に白8%、左の端に白い線（1.5px）
- 溝の幅と、映す幅の比（ここでは 2.5倍）で歪みの強さが決まる。リブガラス・モールガラスとも呼ばれる
使いどころ: 写真や色の上に柔らかい質感を足したい、インテリア・コスメ・ホテルなどのサイトに。
