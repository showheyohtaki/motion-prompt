Motion Prompt #259

どういうものか: 溶けた金属のように光が流れる
見本で起きること: 明るい地の大きな文字 FLOW と球の中を、黒・青・白の映り込みが、うねりながら流れ続ける。
仕様:
- 表示域 511×170。明るい地（白→#F1F0EE）に文字 FLOW（84px）と球（半径52）。4.7秒でひと回り（パックの周期9.4秒で2回）
- 模様の値 v = sin(0.03x + 2.3·sin(0.045y + a) + a) + 0.55·sin(0.08y − 0.018x + 2a) + 0.3·sin(0.05(x+y) − a)、a = 2πt/4.7
- 色は v×0.22 + y×0.002 を 黒 #1E1E21 → 青 #2F6BEB → #C9D8FB → 白 → #9DB8F6 → 白 → #E4ECFE → #2F6BEB → #1E1E21 の帯に当てる（くり返し）
- 128×43 のマス目で計算して引き伸ばし、文字と球の形で切り抜く。球には左上の白い光と右下の影を重ね、全体に青い光（不透明度0.25・ぼかし14）
- #022 ライトスイープは1本の光が横切る。リキッドメタルは表面全体の映り込みがゆがみながら動く
使いどころ: AI・テック・音楽などの、未来的で手ざわりのある見出しやロゴに。
