Motion Prompt #260

どういうものか: 水の底でゆらめく光の網目
見本で起きること: 青から水色の水の底に、波で集まった白い光の網目がゆらめき続ける。上に見出しと、ゆれる浮き輪とその影。
仕様:
- 表示域 511×170。水の色は上 #2F6BEB → 下 #9DB8F6。4.7秒でひと回り（パックの周期9.4秒で2回）
- 光の網目: 向き（0.35・2.45・4.15 rad）と細かさ（0.050・0.043・0.057）の違う3つの波 sin(f·u + m·a + 1.6·sin(0.6f·v + n·a)) を足し、和が0に近い所ほど明るくする: 明るさ = (1 − |和| / 1.6)^6（u・v は波の向きとその直角の座標）
- a = 2πt/4.7。m・n は整数（1と−1、−1と2、2と1）なので、4.7秒で元の模様に戻る。128×43 のマス目で計算して引き伸ばす
- 明るさ v で水の色を白へ寄せる。浮き輪（半径38・青と白の8色分け）は x を ±10、y を ±5 ゆらし、0.15 rad 傾け、水の底に影
- ふつうは WebGL のシェーダーで画素ごとに計算する。波を重ねて明るい線の網を作る考え方は、本物の水の底で光が集まる所（焦線）のまね
使いどころ: プール・海・リゾート・飲み物など、水の涼しさを感じさせたいサイトの背景に。
