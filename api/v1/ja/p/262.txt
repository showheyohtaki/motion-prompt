Motion Prompt #262

どういうものか: 等高線がゆっくり形を変える
見本で起きること: 明るい地に、山の高さを表す青の濃淡の等高線が何重にも描かれ、山ごとゆっくり動いて線の形が変わり続ける。上に見出しの札。
仕様:
- 表示域 511×170。地は 白 → #F1F5FF。4.7秒でひと回り（パックの周期9.4秒で2回）
- 高さ = 4つの山（中心 (150,70)・(340,110)・(470,30)・(60,150)、半径 70・80・60・55、高さ 1・0.9・0.7・0.6 のガウス）＋ 0.12·sin(0.02x + a)·cos(0.03y − a)。山の中心は 横22・縦14 の円を回る（a = 2πt/4.7、山ごとに位相をずらす）
- 7px のマス目で高さを測り、マーチングスクエアで等高線を引く。高さ −0.08 から 0.1 おきに11本、線幅1.3
- 線の色は低い方から #C9D8FB → #9DB8F6 → #2F6BEB、不透明度 0.55〜1。見出しは白い札
- 地図記号を足さず線だけにすると、模様として背景に使える
使いどころ: アウトドア・旅・地図・不動産など、土地や地形を感じさせたいサイトの背景に。
