// 示例效果: 相机位置不变，只增加焦距，使整个画面按同一比例放大。
// 效果规格:
//   - 镜头：位置和方向固定，高 1.5 m；仅焦距从 330 px→1200 px，显示为 24mm→87mm，约 3.6×。
//   - 指数插值：f = 330 × (8/2.2)^p；p 在 0.5–3.4 s 内按三次缓入缓出变化，历时 2.9 s。
//   - 主体：人物静立在前方 8 m，最终大小与第 03 项推镜头相同，约 3.6×。
//   - 无视差：前景木桩、岩石、人物、建筑和山均按相同比例放大，遮挡关系不变。
//   - 回位：3.4–4.2 s 停留，最后 0.5 s 交叉淡化回起点，每轮 4.7 s。
//   - 右上角以 mm 显示焦距：24mm→87mm。
// 适用场景: 适合不移动相机地突出某个点，画面比推镜头更平面、更像观察。
// 标签: zoom, zoom in, focal length, lens, magnify, telephoto, camera move
