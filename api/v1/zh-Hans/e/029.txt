// 跟拍 / Tracking shot
// 分类: camera (镜头运动与转场) · element 05 · 子类: 镜头运动
// 示例效果: 相机与步行人物同速横移，人物保持居中，近处木桩掠过更快。
// 效果规格:
//   - 镜头：以恒定 1.7 m/s 向右横移，4.7 s 内 x = -4.0 m→+4.0 m；高 1.3 m，朝向正前方，无缓动。
//   - 主体：人物沿与相机相同的 x 行走，深度 7.5 m，始终居中；手脚按 sin(u×7)×0.42 rad 摆动。
//   - 视差：深度 4 m、间距 1.6 m 的木桩向左流动最快，其次是树、48 m 处建筑；山几乎不动。
//   - 右上角显示 → 1.7m/s。
//   - 每 4.7 s 跳回起点：木桩与地面网格在接缝处对齐，但背景建筑和树会跳位。
// 适用场景: 适合跟随行走或奔跑的人物，在保持运动感的同时展示表情和动作。
// 标签: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// 尺寸: 539x208 px · 周期: 9.4 s
// Needs: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/zh-Hans/kit/camera.js
// 动态示例: https://showheyohtaki.github.io/motion-prompt/#029
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用前已清空并包裹 save/restore；w、h 为尺寸，u 为周期内秒数。画面仅由 u 决定。
// 以下是示例代码，CELLS、常量和辅助函数位于 kit 中。

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
