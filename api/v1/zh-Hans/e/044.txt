//   - 两幅画面的相机均固定：A 高 1.4 m，B 高 1.6 m、俯仰 +0.1 rad；主体也不动。
//   - 0–1.5 s 仅前画面可见，3.0–4.7 s 仅后画面可见。
//   - 每 4.7 s 交替 A→B、B→A，往返 9.4 s；右上角显示 A → B / B → A。
