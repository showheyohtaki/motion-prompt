// 划像转场 / Wipe
// 分类: camera (镜头运动与转场) · element 21 · 子类: 转场
// 示例效果: 竖直边界从左移到右，其后下一画面替换当前画面。
// 效果规格:
//   - 衔接：1.7–2.8 s，历时 1.1 s；边界从左侧画面外 x = -4 px 移至右侧画面外 x = 543 px。
//   - 三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 边界左侧显示后画面，右侧显示前画面；两幅画面均不移动，通过裁切显现而非推挤。
//   - 边界为 4 px 蓝色竖线，仅移动时可见。
//   - 两幅画面的相机和主体均固定。
//   - 每 4.7 s 交替 A→B、B→A，往返 9.4 s；右上角显示 A → B / B → A。
// 适用场景: 适合清晰标示场景或话题变化，或切换对照的两侧。
// 标签: wipe, linear wipe, reveal, clip, edge, left to right, transition
// 尺寸: 539x208 px · 周期: 9.4 s
// Needs: kit camera -> https://showheyohtaki.github.io/motion-prompt/api/v1/zh-Hans/kit/camera.js
// 动态示例: https://showheyohtaki.github.io/motion-prompt/#045
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用前已清空并包裹 save/restore；w、h 为尺寸，u 为周期内秒数。画面仅由 u 决定。
// 以下是示例代码，CELLS、常量和辅助函数位于 kit 中。

// @element 21
// 21 ワイプ
CELLS[20] = shot(abCell((k, w, h, u, A, B) => {
  const p = eIO(P(u, 1.7, 2.8)), ex = p * (w + 8) - 4;
  A(k, w, h);
  if (p > 0) { k.save(); k.beginPath(); k.rect(0, 0, ex, h); k.clip(); k.fillStyle = '#fff'; k.fillRect(0, 0, w, h); B(k, w, h); k.restore(); }
  if (p > 0 && p < 1) { k.fillStyle = C.blue; k.fillRect(ex - 2, 0, 4, h); }
}));
