// 轮廓光 / Rim light
// 分类: photo (摄影效果、光线与风格) · element 02 · 子类: 布光与时段
// 示例效果: 周围变暗，人物左右后方的两盏灯仅勾亮头肩两侧细边，右下示意图显示灯位。
// 效果规格:
//   - 场景 1：人物半身像位于 y 150 的地平线前，头部中心 x 270、y 78，半径 29 px，无五官或头发。
//   - 背景由明转暗，天空 #2B2D33、地面 #24252A；人物 #4D5A75→#1F2128。
//   - 亮边：两份琥珀色 #FFC75A 人物副本分别左移与右移 3.5 px、上移 2.5 px，置于暗色人物后，形成宽 3.5 px 的边缘。
//   - 右下 66×66 px 俯视图显示后方左右 ±135° 灯位，右上显示 ±135°。
//   - 时间：0.4–1.4 s 效果渐入，保持到 4.0 s，至 4.8 s 消退；每轮 5 s，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合从深色背景分离人物或产品，并显示外形。
// 标签: rim light, rim lighting, edge light, backlight, kicker, outline, studio
// 尺寸: 539x208 px · 周期: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/zh-Hans/kit/photo.js
// 动态示例: https://showheyohtaki.github.io/motion-prompt/#098
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用前已清空并包裹 save/restore；w、h 为尺寸，u 为周期内秒数。画面仅由 u 决定。
// 以下是示例代码，CELLS、常量和辅助函数位于 kit 中。

// @element 02
// リムライト: 周りが暗くなり、斜め後ろ左右の2灯で頭と肩の輪郭だけが細く光る
CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
