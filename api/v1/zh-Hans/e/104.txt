// 蓝调时刻 / Blue hour
// 分类: photo (摄影效果、光线与风格) · element 08 · 子类: 布光与时段
// 示例效果: 日落后天空变为两层深蓝，窗户和路灯亮成琥珀色，人物成为深蓝形状。
// 效果规格:
//   - 场景 1：人物半身像位于 y 150 的地平线前，头部中心 x 270、y 78，半径 29 px，无五官或头发。
//   - 太阳半径 18 px、x 120；效果到达 70% 时从 y 40 沉到 y 190，效果 40%–80% 期间淡出。
//   - 天空顶部 #2C3B5E、近地平线 #4A6191，地面 #283452，建筑 #34446B，人物 #1C2439。
//   - 每三扇窗亮一扇，路灯灯泡也变为 #FFC75A；灯泡周围有半径 13 px 和 8 px 的平面光晕，#FFE3A3，不透明度 35% 和 60%。
//   - 右上时间 12:00→18:35。
//   - 时间：0.4–1.4 s 效果渐入，保持到 4.0 s，至 4.8 s 消退；每轮 5 s，三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合同时需要蓝色天空与发光灯火的城市夜景。
// 标签: blue hour, twilight, dusk, night city, cityscape, deep blue sky
// 尺寸: 539x208 px · 周期: 5 s
// Needs: kit photo -> https://showheyohtaki.github.io/motion-prompt/api/v1/zh-Hans/kit/photo.js
// 动态示例: https://showheyohtaki.github.io/motion-prompt/#104
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D，调用前已清空并包裹 save/restore；w、h 为尺寸，u 为周期内秒数。画面仅由 u 决定。
// 以下是示例代码，CELLS、常量和辅助函数位于 kit 中。

// @element 08
// ブルーアワー: 日が沈んだ後、空が深い青になり、窓と街灯の暖かい光が灯る
CELLS[7] = cell((k, u) => {
  const a = env(u);
  const p = pal(BASE, NIGHT, a);
  stagePortrait(k, p, {
    sun: [120, lerp(40, 190, P(a, 0, 0.7)), 18, 1 - P(a, 0.4, 0.8)],
    after: D => { const k2 = D.k; k2.save(); k2.globalAlpha = 0.35 * a; D.circ(413, HZ - 53, 13, BASE.glow); k2.globalAlpha = 0.6 * a; D.circ(413, HZ - 53, 8, BASE.glow); k2.restore(); D.circ(413, HZ - 53, 4, p.bulb); }
  });
  bust(k, PX, PY, PR, p.person);
  hud(k, clock(lerp(720, 1115, a)));
});
