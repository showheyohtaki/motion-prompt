Motion Prompt #045

含义：移动的边界逐步替换画面
示例效果：竖直边界从左移到右，其后下一画面替换当前画面。
规格：
- 衔接：1.7–2.8 s，历时 1.1 s；边界从左侧画面外 x = -4 px 移至右侧画面外 x = 543 px。
- 三次缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
- 边界左侧显示后画面，右侧显示前画面；两幅画面均不移动，通过裁切显现而非推挤。
- 边界为 4 px 蓝色竖线，仅移动时可见。
- 两幅画面的相机和主体均固定。
- 每 4.7 s 交替 A→B、B→A，往返 9.4 s；右上角显示 A → B / B → A。
适用场景：适合清晰标示场景或话题变化，或切换对照的两侧。
