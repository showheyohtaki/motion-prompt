请使用“光标跟随（Cursor follower）”，它属于“落地页与网页效果”。
Motion Prompt #083

含义：图形略带延迟地跟随指针
示例效果：光标在页面移动，橙色圆略微落后跟随。
规格：
- 光标路径 x = 255 + 175·sin(2πt/4.8)，y = 86 + 46·sin(4πt/4.8)，横向 8 字形，每 4.8 s 一圈。
- 橙圆半径 17、不透明度 0.88，画在光标下方。
- 跟随规则：60 fps 下每帧走完剩余距离的 12%，x += (cursor x − x) × 0.12。
- 保留可见的箭头光标。
适用场景：适合品牌站和作品集，增添趣味和直接交互感。
