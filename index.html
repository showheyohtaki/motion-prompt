AIに頼むための「名前」のライブラリ

AIを指揮するクリエイティブディレクターへ

モーショングラフィックス、カメラワーク、UIパーツ、LP・Webサイトの演出、写真の表現の名前を、動く見本つきで並べました。プロンプトをコピーすれば、動きの仕様と参考実装も一緒に渡せます。

スキルで導入

ターミナルで実行します。入れたあとは、AIに「motion-prompt のライブラリ出して」と頼むと、このギャラリーが開きます。選んで「AIに渡す」を押すと、AIに届きます。

npx skills add showheyohtaki/motion-prompt

プロンプトで導入

下の文を Claude Code や Codex に貼ると、AIがスキルを入れて使い方を教えてくれます。

https://github.com/showheyohtaki/motion-prompt を読んで、motion-prompt スキルをこの環境に入れてください。入れたら、使い方を3行で教えてください。

使い方

  1. 1

    ライブラリを出してもらう

    motion-prompt スキルを入れたAIに「motion-prompt のライブラリ出して」と頼みます。このギャラリーがブラウザで開きます。

  2. 2

    見ながら選ぶ

    使いたい見本の「選ぶ」を押します。いくつでも選べます。選んだ物は画面の下に並び、「冒頭のタイトルに」のような一言のメモも書けます。

  3. 3

    AIに渡して、頼む

    「AIに渡す」を押すと、選んだ物がAIに届きます。あとは「この動画の冒頭をこんな感じに編集して」と頼みます。このボタンは、AIがライブラリを開いたときに出ます。

こう話しかけます

名前や番号を覚えていなくてかまいません。分からないときは、辞書を引くようにライブラリを出してもらってください。

  • motion-prompt のライブラリ出して
  • どんなカメラワークがある？一覧見せて
  • （選んで渡したあと）この動画の冒頭をこんな感じに編集して

スキルが無いとき・番号が分かるとき

スキルを入れていないAIには、画面の下の「選んだ物をコピー」で作った文を貼ってください。見本と仕様のURLが入っています。1つだけなら、詳細の「プロンプトをコピー」も使えます。

番号が分かっていれば、「motion-prompt で #012 と #045 を使って」のように直接頼むこともできます。

参考実装について
